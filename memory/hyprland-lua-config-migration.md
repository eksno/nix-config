# Hyprland retires `.conf` — hard deadline at 0.57

Upstream replaced the hyprlang `.conf` format with a Lua 5.4 config runtime.

| Version | State |
|---|---|
| 0.55 | `hyprland.lua` introduced; hyprlang **deprecated**, no new features |
| 0.56.1 | Compositor shows an on-screen **deprecation notice** for `.conf` (PR #15538) |
| **0.57** | **`.conf` removed.** PR #15538 body: *"Adds a notification about .conf being removed starting 0.57"* |

Sources: <https://hypr.land/news/26_lua/>, <https://wiki.hypr.land/Configuring/Start/>,
<https://github.com/hyprwm/Hyprland/pull/15538>

## Why this repo is exposed

- All ~1230 lines under `dotfiles/default/hypr/**.conf` are hyprlang across 6 hosts / 7 users.
- `system/lib/dotfiles.nix:136-145` composes `hyprland.conf` from two `source =` lines.
- `./update.sh` runs `nix flake update` **unconditionally**, so the 0.57 bump arrives
  with no gate. Every host boots to an empty config the day nixpkgs lands it.
- As of 2026-08-18 nixpkgs master is still `0.56.2` — runway exists, but no warning shot.

## Migration facts

- New path: `$XDG_CONFIG_HOME/hypr/hyprland.lua`. Hyprland picks `.lua` if present, else falls
  back to `.conf`. Checked **once at startup** — log line: `[cfg] Lua config not found, using legacy config`.
- `source =` → lua `require("path/to/file")`; supports `/` or `.` separators, wildcards
  (`require("./stuff/*")`) and absolute paths. Each `require()` is its own error scope.
- API surface is fully typed in shipped stubs: `/run/current-system/sw/share/hypr/stubs/hl.meta.lua`
  (1777 lines, autogenerated). Point an LSP at it via `.luarc.json`.
- Upstream example: `/run/current-system/sw/share/hypr/hyprland.lua`.
- `hyprctl repl` / `hyprctl eval` only work under the Lua config manager — on a `.conf`
  session they return *"eval is only supported with the lua config manager"*. Useful as a
  one-command check for which manager is live.
- Shape: `hl.config({ general = { ... } })`, `hl.bind("SUPER + Q", hl.dsp.exec_cmd("kitty"))`,
  `hl.monitor({...})`, `hl.window_rule({ name=, match={}, ... })`, `hl.env("K","V")`,
  `hl.on("hyprland.start", function() hl.exec_cmd("waybar") end)`, `hl.animation({leaf=...})`,
  `hl.curve(name, {type="bezier"|"spring", ...})`.
- `hyprconf2lua` (PyPI) exists as an automated converter — unvetted, not used here.

## Already-dead options still in the repo (0.56 removed these)

Found by diffing every `section:key` in the tree against `hyprctl descriptions -j`.
All in `teto`'s chain (hosts `lappy`/`chrono`) — not loaded on verse/lewis, so `hyprctl
configerrors` is silent here and hides them:

- `decoration:drop_shadow|shadow_ignore_window|shadow_offset|shadow_range|shadow_render_power|col.shadow`
  → moved into the `decoration:shadow { enabled, ignore_window, offset, range, render_power, color }` block
- `dwindle:pseudotile`, `dwindle:no_gaps_when_only` → removed
- `master:no_gaps_when_only`, `master:always_center_master` → removed
- `misc:vfr` → `debug:vfr` (see [[../FIXES.md]] 2026-05-23)
- `windowrulev2 =` (teto) → `windowrule` block form
